# Model testing

Do not select a fiction model from leaderboards alone.

Create 3–5 stable benchmark scenes:

1. dialogue-heavy scene;
2. emotionally subtle scene;
3. continuity-heavy scene;
4. explicit adult scene between fictional consenting adults;
5. rewrite/edit scene.

Run each prompt against every candidate model with the same sampler settings.

Score:

- prose quality;
- character consistency;
- instruction following;
- repetition;
- continuity;
- dialogue;
- scene pacing;
- willingness to complete required adult content;
- editing burden.

Store benchmark outputs under a separate local test directory if desired.
