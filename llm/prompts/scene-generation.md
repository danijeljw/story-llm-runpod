# Scene generation

Write the requested scene as publication-oriented prose.

Use the provided:

- style guide;
- character information;
- continuity context;
- chapter objective;
- scene objective.

Start where the supplied previous-scene context ends.

Do not:

- recap information the reader already knows;
- repeat the scene objective verbatim;
- add headings unless requested;
- resolve future plot points early;
- change established physical details;
- end the scene simply because a target token count has been reached.
